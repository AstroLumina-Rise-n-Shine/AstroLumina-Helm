NOT in this chart (create once per cluster rebuild, values from Doppler CLI
on your laptop, kubectl on the control plane over ssh):
  - doppler-token ServiceToken Secret in doppler-operator-system
    (referenced as {{ .Values.doppler.tokenSecret }})
  - real {{ .Values.image.pullSecret }} docker-registry Secret in
    {{ .Values.namespace }} (a pull secret cannot be synced by the Doppler
    operator, so it is created imperatively and never shipped in git)

  - traefik-dashboard-auth Secret in {{ .Values.namespace }}
    (htpasswd users line for the dashboard basicAuth middleware)
{{- end }}

values (same as the Kustomize manifests — this chart ships no Secret
objects at all).
